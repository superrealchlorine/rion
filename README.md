# rion

Minimalist SDL2 canvas runtime for Chloride applications.

## Dependencies

- C99 compiler (gcc or clang)
- make
- libsdl2-dev

On Debian/Ubuntu:
  sudo apt install build-essential libsdl2-dev

## Building & Installation

  make
  sudo make install

## Usage

  rion chloride.chlorine.me:49130
